# ⚖️ 다우 30종목: 가격가중 vs 시가총액가중

**다우존스 산업평균은 주가(1주 가격)에 비례해 비중을 매깁니다. 같은 30종목을 시가총액 비중으로 바꿔 국내 상장 분배형 ETF로 운용했다면 2010~2026년 수익률이 어땠을지 백테스트했습니다. 시가총액가중이 연 1.0%p 높았지만 통계적으로 유의하지 않았습니다(알파 t = 0.93). 2010~2017년은 가격가중이 앞섰고, 2018년 이후 Apple·Microsoft·NVIDIA 장세에서 시가총액가중이 뒤집었습니다.**

> 포트폴리오용 개인 분석입니다. 실제 매매·주문 코드는 없고, 투자 권유가 아닙니다.

## 질문

주가 400달러·발행주식 10억 주(시총 4,000억 달러)인 A와 주가 100달러·100억 주(시총 1조 달러)인 B가 있다고 합시다. 가격가중이면 A 80% : B 20%, 시가총액가중이면 A 29% : B 71%입니다. 종목은 그대로 두고 비중 규칙만 바꾸면 성과가 얼마나 달라질까요?

## 설계

| 항목 | 내용 |
|---|---|
| 종목 | 각 시점의 실제 다우 30종목 (2010~2026년 편입 변경 9회 반영, 탈퇴 종목 포함) |
| 가격가중 | 비중 ∝ 실제 주가. 편입 변경·분할·스핀오프 때만 다시 맞춤 (실제 다우와 일별 상관 0.9998) |
| 시가총액가중 | 비중 ∝ 주가 × 발행주식수, 분기 말 재조정. 발행주식수는 직전 월말까지 공개된 시가총액으로 계산 |
| 상품 | 국내 상장 해외주식형 ETF, 월말 분배 (2025.7 시행령 개정으로 해외주식형 TR 불가) |
| 세금 | 분배금 15.4% 과세 후 재투자, 청산 시 매매차익 15.4% |
| 비용 | 총보수 연 0.35% (두 방식 동일), 거래비용 편도 0.05% |
| 통화 | USD / 원화 환노출 / 원화 환헤지 |

## 핵심 결과 (2010-01-04 ~ 2026-10-29, 원화 환노출)

| | 가격가중 | 시가총액가중 | 차이 |
|---|---:|---:|---:|
| CAGR | 12.79% | 13.80% | +1.01%p |
| 청산 후 CAGR | 11.98% | 12.92% | +0.94%p |
| 변동성 | 17.1% | 17.8% | +0.7%p |
| MDD | −32.7% | −27.3% | +5.4%p |
| 샤프 | 0.65 | 0.69 | +0.03 |
| 상위 5종목 비중(2026) | 36% | 71% | +34%p |
| 연 회전율 | 5.1% | 6.8% | +1.8%p |

| 검증 | 가격가중 | 시가총액가중 | 알파 t값 |
|---|---:|---:|---:|
| 2010~2017 | 12.40% | 10.25% | −1.76 |
| 2018~2026 | 13.20% | 17.12% | 1.49 |
| 거래비용 4배 | 12.77% | 13.77% | 0.93 |
| 시총 재조정 연 1회 | 12.79% | 14.26% | 1.24 |
| 세금 없음(참고) | 13.19% | 14.18% | 0.93 |

- 시가총액가중의 우위는 Apple(+31%p)·Microsoft(+30%p)·NVIDIA(+10%p) 세 종목 기여에서 거의 다 나왔습니다. 가격가중은 Goldman Sachs·Caterpillar 같은 고가주에서 앞섰습니다.
- 시가총액가중 다우는 상위 5종목(NVIDIA·Apple·Microsoft·Alphabet·Amazon) 비중이 71%라, 다우 고유의 업종 분산이 사라집니다.
- 원화 환노출과 환헤지의 연 수익률은 거의 같았고(13.80% vs 13.78%), 환노출 쪽 낙폭이 더 작았습니다.

자세한 내용은 `다우_가격가중_vs_시총가중_보고서.pdf`(7쪽)를 보세요.

## 왜 2010년부터인가

- 1995~1999년에는 다우 30종목 중 최대 10종목(코닥, 옛 GM, 시어스, 텍사코 등)이 무료 일별 시세가 없습니다. 지수의 3분의 1을 대체값으로 채우면 가중 방식이 아니라 대체 방식의 차이를 재게 됩니다.
- 2009년 이전에는 탈퇴 종목의 발행주식수 시계열을 구할 수 없습니다.
- 2010년 이후 대체가 들어간 곳은 두 군데뿐입니다. 옛 Alcoa(2010.01~2013.09)는 두 포트폴리오에서 같이 뺐고(29종목 운용), Walgreens(2018.06~2024.02, 2025년 상장폐지)는 월말 실제값 사이의 일별 경로만 보간했습니다.

## 실행 방법

```bash
pip install pandas numpy matplotlib statsmodels yfinance requests pymysql python-dotenv python-docx pyarrow
python data.py          # 데이터 → data/ (저장소에는 올리지 않음, 이어받기 가능)
python run.py           # 백테스트·검증·강건성·그림 → results/ (약 5분)
python build_report.py  # 보고서 docx
```

같은 입력이면 같은 결과가 나옵니다(난수 없음).

## 한계

- 1990년대 후반~2000년대 초 기술주 버블·붕괴 구간은 데이터 제약으로 포함하지 못했습니다.
- 시가총액은 월말 값을 그날 주가 변화로 늘리거나 줄여 썼고, 유동주식 조정은 하지 않았습니다.
- 세금은 단순화했습니다(과표기준가, 금융소득 종합과세, 연금·ISA 계좌 미반영).
- 환헤지 손익은 한·미 3개월 금리차로 근사했습니다.
- 생존편향: 편입 이력대로 탈퇴 종목을 포함했지만, 옛 Alcoa는 시세가 없어 뺐습니다(두 방식 동일 적용).
