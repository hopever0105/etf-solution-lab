\## 🧱 지수 설계



| 항목 | 내용 |

|---|---|

| 지수 A | 국내 AI·반도체·전력 10종목, 종목당 25% 상한, 분기 리밸런싱 |

| 구성 규칙 | 쿼터 CHIP 4 / POWER 3 / HW 2 / PLAT 1, 버퍼 1.5 |

| 임시 리밸런싱 | 최대 비중이 3거래일 연속 30% 초과 시 |

| 에너지 바스켓 | 정유·연료용 가스·연료 소매 업종 보통주, 시가총액 3,000억 이상, 63일 평균 거래대금 10억 이상 (후보 17개 → 3개) |

| 바스켓 가중 | 3종목이라 25% 상한을 적용할 수 없어 동일가중 |

| 결합 | 지수 A 80% + 에너지 바스켓 20%, 분기 리셋 |

| 한국전력 | 에너지 바스켓에서 제외, 지수 A에만 포함 (종목 중복 없음) |

\## 🚀 실행 방법



```bash

conda activate ta\_env

pip install pandas numpy sqlalchemy pymysql requests tqdm finance-datareader tvdatafeed-enhanced tradingview-screener

```



1\. 위 파일을 `00 → day1 → day2 → day3 → day4 → day5` 순서로 실행합니다.

2\. 파일은 `#%%` 셀 단위이며 Spyder에서 `%runcell`로 실행합니다. 이미 DB에 데이터가 있으면 수집 셀은 건너뜁니다 (`RUN\_DOWNLOAD = False`).

3\. Spyder에서는 `Tools > Preferences > Python interpreter`에서 `ta\_env`의 `python.exe`를 선택하고 커널을 재시작합니다.



🔐 접속 정보는 코드에 쓰지 않고 환경변수로 읽습니다.



```bash

setx DB\_USER "사용자"

setx DB\_PW "비밀번호"

setx ECOS\_KEY "한국은행 ECOS 키"

```

\## ⚠️ 한계



\- 가격지수 기준이며 배당, 보수, 세금, 거래비용은 반영하지 않았습니다.

\- 참여율 20%는 가정이며 실무 관행은 확인하지 못했습니다.

\- ETF 요건은 언론 보도 기준이고 법령 원문은 확인하지 못했습니다.

\- 주식과 상품선물의 단일 ETF 편입 가능 여부, 거래소·지수산출기관의 승인 절차는 확인하지 못했습니다.

\- 운용 규모 100억 원 초과 시 유동성 제약을 반영한 백테스트는 하지 않았습니다.

\- 최근 1년·3년 수익률의 B 20%는 에너지 바스켓을 3종목으로 고정해 재구성한 값입니다.
